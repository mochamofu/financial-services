# ToriiGate 事業計画

**対AIアクセス制御ゲートウェイ — 月額サブスクリプションSaaS**

> 調査の根拠は [market-research.md](./market-research.md)。本書は「どう売るか・何を売るか」の意思決定をまとめる。

---

## 0. 一行で言うと

**「AIエージェント／AIクローラーが、あなたのサイト・API・社内システムにアクセスするのを、見える化し、選別し、止め、必要なら課金する」ゲートウェイを、日本の中堅企業に月額で売る。**

鳥居（Torii）は「くぐってよい者と、そうでない者を分ける結界」。プロダクト名はここから。

---

## 1. なぜ今、なぜこの形か（調査からの結論）

大手セキュリティ企業の勝ちパターン（[調査論点1](./market-research.md#論点1セキュリティ大手の成長史--勝ちパターン)）は時代を超えて5つ：**①無料で配って法人課金 ②他社の流通に相乗り ③脅威イベントを起爆剤に ④データのネットワーク効果 ⑤既存勝者が追随できない設計**。

しかし「AIアクセス遮断」を**単機能でグローバルに売る**のは、Cloudflareらによる遮断機能の無料化・デフォルト化に正面から潰される（[仮説の総合判断](./market-research.md#4-仮説の総合判断)）。そこで勝ちパターンを、**大手が手薄な4つの空白**に適用する：

| 空白 | ToriiGateの打ち手 | 勝ちパターン対応 |
|---|---|---|
| **日本市場に専業ベンダー不在** | 日本語UI・国内商習慣（設定代行込み）・補助金対応・法令(30条の4/AI事業者GL)の言葉で売る | ⑤追随されにくい局地戦 |
| **Web/CDNの外側（API・社内）が無防備** | ASGIミドルウェア＋リバースプロキシで、CDNに載っていないAPI/社内アプリも保護 | ⑤大手の死角 |
| **Web Bot Auth実装層が薄い** | RFC 9421署名の検証・エージェントレジストリを標準搭載 | 標準に先回り |
| **無料と$3,490/月の価格空白** | 可視化無料→月額29,800円〜の中間帯 | ①無料で配って法人課金 |

## 2. 何を売るのか（プロダクト）

「セキュリティソフト」を名乗るが、買い手の課金理由は3層で異なる。ここを取り違えると売れない。

1. **コスト削減として売る（SMBの入口）** — AIクローラーの無駄アクセスが従量課金・帯域・サーバ負荷を食う。「[20万円課金事故](./market-research.md#論点3gtm価格チャネルと日本市場)」を防ぐ実利。
2. **資産防衛として売る（メディア/EC）** — コンテンツの無断学習・スクレイピングを止める。著作権法30条の4は「技術的措置を講じていること」に意味を持たせる → **本製品の導入自体が法的ポジションを強くする**。
3. **ガバナンス/コンプライアンスとして売る（大企業）** — AI事業者ガイドライン第1.2版のAIエージェント統制。「自社サイト・APIに、どのAIエージェントがアクセスしているかを説明できる」統制レポート。

**プロダクトの技術的な核**（`gateway/` に実装、stdlib中心・依存最小）：
- **多層検知**：①トラップ（ハニーポット/脆弱性プローブ）②身元（UA署名＋公開IPレンジ照合でなりすまし検知）③フィンガープリント（ブラウザ詐称の検出）④振る舞い（レート・累犯）。
- **段階的アクション**：allow / block(403) / **PoWチャレンジ**(JSで解かせ人間コストは一瞬・大量自動化は非経済的に) / throttle(429) / tarpit / **monetize(402 = pay-per-crawl)** / monitor。
- **Web Bot Auth**：Ed25519署名を検証し、「正当なエージェントは通し、詐称は弾く」。市場が「遮断→選別」へ動く先を取る。
- **2つの導入形態**：既存アプリを1行でラップする**ASGIミドルウェア**、CDN移行なしで前段に挟む**リバースプロキシ**。SMBは後者（設定代行込み）で、開発者は前者で。
- **ダッシュボード**：誰が来て何を止めたかを可視化（無料プランの主役）。

## 3. どう売るのか（GTM — 段階別）

セキュリティはPLG単独では売れない（調査で確認）。段階を分ける。

### フェーズ 0→1（〜10社、〜6ヶ月）
- **ICP**：AIクローラー被害が金額で見えているメディア／EC／コンテンツ企業のWeb・インフラ担当。
- **価格**：**可視化無料**（検知レポート＋ダッシュボード）→ 有料は月額 **29,800円**（Starter）単一。差別化はリクエスト数上限のみ。DataDomeの$3,490/月とCloudflareセルフサーブの間の空白帯を取る。
- **チャネル**：**創業者直販のみ**。代理店契約はまだ結ばない。導入は**設定代行込み**（日本の商習慣）。
- **獲得**：「AIクローラー ブロック」「クラウド 従量課金 事故」のコンテンツSEO＋**無料診断ツール**（自社サイトにどのAIボットが来ているか即座に可視化）でインバウンド。
- **やらないこと**：席数課金、エンタープライズSLA約束、多段代理店登録。

### フェーズ 1→10（10〜100社、ARR 〜1億円）
- **パッケージ2層化**：SMBセルフサーブ（月額数万円・クレカ）と、ミッドマーケット（年契約・SSO・監査ログ・SLAをここで初めて有料ゲート化）。
- **補助金チャネル起動**：デジタル化・AI導入補助金のITツール登録＋顧客のSECURITY ACTION宣言支援をオンボーディングに組込み、SMBの実質負担を下げる。
- **準MSPチャネル**：Web制作会社・ホスティング・保守運用会社に再販マージン＋運用ダッシュボードを提供（Huntress型の日本版）。フルのディストリビューター網はまだ使わない。
- **AWS Marketplace出品**：掲載コストは低く、後のエンタープライズ決済経路として先に整備。
- **証拠づくり**：業種別の被害額・削減額事例を3本以上作り、代理店に渡せる「売れる型」を完成。

### フェーズ 10→100（エンタープライズ・スケール）
- **エンタープライズ・プラン**：カスタム価格・専任サポート・AI事業者ガイドライン対応の統制レポート。AWS co-sell（ISV Accelerate）でクラウドコミット予算を取る（案件+40%/成約+20%）。
- **ディストリビューター起用**：ここで初めて一次ディストリビューターと組む。「注力商品」に選ばれる条件（実績・マージン・検証済み提案書）が揃ってから。
- **収益軸の追加**：Pay Per Crawl型の「AIアクセス課金の代行」でSaaS月額＋徴収額レベニューシェアの複合モデルへ（Cloudflareの市場教育に相乗り）。

## 5. 競合ポジショニング

| | Cloudflare | DataDome/HUMAN | Anubis(OSS) | **ToriiGate** |
|---|---|---|---|---|
| 導入 | CDN移行前提 | CDN前提・営業主導 | セルフホスト | **ミドルウェア/プロキシ、CDN移行不要** |
| 価格 | 無料〜非公開Ent | $3,490/月〜 | 無料 | **¥29,800/月〜（中間帯）** |
| API/社内保護 | △ | △ | × | **○（Webの外側が主戦場）** |
| Web Bot Auth | 主導 | 対応進行 | × | **標準搭載** |
| 日本語/商習慣/補助金 | 代理店任せ | × | × | **○（一次サポート）** |

**正面衝突を避ける**：Cloudflareが無料化する「Webの遮断」ではなく、**Webの外側（API・社内エージェント）＋日本＋身元検証**で戦う。Cloudflareのpay-per-crawl等の市場教育には相乗りする。

## 6. リスクと対応

| リスク | 対応 |
|---|---|
| 遮断機能の無料化・コモディティ化 | 価値を「遮断」でなく「選別・身元検証・統制レポート・API保護」に置く |
| 検知の消耗戦（Anubis突破） | 単一手法に依存せず多層化＋SaaS側で署名DB・IPレンジを日次更新。PoWは補助 |
| 正当なエージェントの誤遮断（Perplexity論争型） | 既定でAI検索・ユーザー代理エージェントは通す。Web Bot Authで「通してよい者」を積極特定 |
| 大手のAPI領域参入（Okta等） | 彼らは社内IAM側。こちらは「外から来るエージェント」の入口ゲート。連携も選択肢 |
| 市場の絶対額が小さい | ボット遮断単体でなくAIアクセス制御＋課金＋統制の広い市場定義で見る |
